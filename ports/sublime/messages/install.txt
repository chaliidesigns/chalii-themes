Chalii Themes
==============

Thanks for installing Chalii Themes — a premium pair of light and dark color
schemes with warm orange accents and excellent readability.

Activate a scheme:

    Preferences > Select Color Scheme...
        - Chalii Light
        - Chalii Dark

Or set in Preferences.sublime-settings:

    {
        "color_scheme": "Packages/Chalii Themes/Chalii Dark.sublime-color-scheme"
    }

Source: https://github.com/chaliidesigns/chalii-themes
Issues: https://github.com/chaliidesigns/chalii-themes/issues
