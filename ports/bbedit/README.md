# Chalii Themes — BBEdit

`.bbcolors` plist files for BBEdit.

## Install

Double-click each `.bbcolors` file in Finder — BBEdit will install it. Or
manually copy into:

```
~/Library/Application Support/BBEdit/Color Schemes/
```

Then activate via **BBEdit → Preferences → Editor → Text Colors**.

## Source of truth

Generated from `source/palette.json`. Regenerate with `npm run build:bbedit`.
